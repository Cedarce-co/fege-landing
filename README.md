# Fege landing

Modern Fege marketing site and buyer Deal Page, built with Next.js, Tailwind CSS, and Framer Motion.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS v4
- Framer Motion (hero + section motion, reduced-motion aware)
- Copy from `docs/fege-website-build-guide.md`

## Routes

| Route | Purpose |
|---|---|
| `/` | Marketing home |
| `/how-it-works` | Four-step flow |
| `/for-sellers` | Seller benefits |
| `/for-buyers` | Buyer protection |
| `/download` | Waitlist / store redirect |
| `/d/demo` | Sample buyer Deal Page |

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and [http://localhost:3000/d/demo](http://localhost:3000/d/demo).

Items marked `[CONFIRM]` are intentional placeholders from the build guide.
